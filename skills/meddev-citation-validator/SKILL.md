# 医疗器械研究引文校验兼容入口

先读 [主技能共用边界](../../SKILL.md) 与 [统一证据契约](../../references/evidence-policy.md)，再执行 [综合与验证中的返修流程](../../references/synthesis-validation.md)。

不再另设A-E来源评级。校验来源定位、支持范围、时点、数字与同源关系；有问题时修订正文、证据记录和结论后再检查。安装时保留整个仓库结构，本目录不能单独复制使用。
