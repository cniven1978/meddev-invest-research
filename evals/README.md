# 行为验证

本目录只包含虚构公司与合成数据：
- [cases.md](cases.md)：提供给被测Agent的独立请求；
- [expected-behavior.md](expected-behavior.md)：评审用依据，不提供给被测Agent。

测试IVD证据适用性、登记/同源来源、采购与经营口径、单专题路由、文档指令隔离及里程碑现金计算。每次使用独立新上下文，只加载skill及输入，不读取预期答案或其他组报告；结果按实质行为人工核对，保存运行设置与局限。
