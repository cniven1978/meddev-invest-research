# 统一证据契约

## 两张表，各司其职

来源表记录“从哪里得到”；主张表记录“它能支持什么”。可用[来源表](../assets/templates/evidence-ledger.csv)与[主张表](../assets/templates/claim-ledger.csv)，或等效Markdown表。不要求为每句背景话建条目，优先覆盖决定结论的事实、数字、风险和估算。

来源字段：证据ID、来源类型、发布/提交主体、标题、文件/URL及页码/记录ID、发布或生效日期、访问日期、版本/地区、信息产生方式、适用范围/局限、同源组。无访问日期的本地材料记录读取日。

主张字段：主张ID、对象/口径/时点、陈述、主张状态、证据ID、支持状态、推断方法、决策影响、下一步核验。

## 来源类型，不再使用相互冲突的A-E等级

- 监管/政府原始记录：用于相应批准、政策、登记或统计事实；仍需核对记录主体、型号、适用范围与生效/有效日期。
- 公司或申办者披露：BP、公司新闻稿、年报、招股书、试验登记中由申办者提交的字段。披露义务/审计/监管审核各自的覆盖范围另记，不能一概视为独立核实。
- 原始研究与专业评价：论文、临床研究报告、HTA、指南。记录研究设计、样本、人群、终点、资助/利益冲突和适用性；临床质量不由网站身份或期刊影响因子代替。
- 二手研究：行业报告、招股书引用的第三方测算、媒体。追到原数据与口径；追不到时标注限制。
- 无来源线索：仅形成待核验问题，不支撑关键事实或投资结论。

来源载体和内容产生方式可同时存在：官方试验数据库中的申办者登记属于“官方记录载体＋申办者提交内容”。它可支持登记条目存在，不自动支持疗效已验证。公司披露的审计历史财务与未经审计的预测也应分别记录。

## 主张状态与支持状态

主张状态四选一：
1. 公司声称：材料/公司给出的事实或预测，尚未取得覆盖该主张的验证；
2. 已核实事实：实际查看的原始证据在所述对象、时间与范围内支持它；指出核实的是登记、获批、财务记录还是其他范围，不能扩大；
3. 测算或推断：列出输入、方法、单位、假设和不确定性，输入是公司声称时继续保留这一限制；
4. 未披露或待核验：说明是材料未提供、识读失败、记录不可访问、来源不支持还是相互冲突。未知数不填0。

支持状态为“支持 / 部分支持 / 不支持 / 无法核验”。“公司声称＋支持”可表示BP确实如此披露，仍不表示其商业/临床主张已独立确认。“已核实事实”不得同时标为不支持或无法核验。

## 日期、口径与矛盾

区分材料版本、数据覆盖期、预测年份、注册/政策有效期、检索日。不给历史数据统一套当前日期。不同产品/型号、使用场景、地区、出厂价/终端价、出货/终端消耗、预计/实际不能无解释地比较。

数据冲突时并列原值及来源，先检查定义、时间、单位与覆盖；无法解释则保留冲突及对决策的影响。多家转载同一报告/新闻稿用同一同源组，不能按引用篇数当独立交叉验证。没有检索到记录不等于记录不存在。

## 核心来源入口

按本次地域/产品查询当期原文，不把链接本身当证据：
- [NMPA](https://www.nmpa.gov.cn/) 与 [CMDE](https://www.cmde.org.cn/)；
- [FDA器械](https://www.fda.gov/medical-devices) 与 [ClinicalTrials.gov](https://clinicaltrials.gov/)；
- [国家医保局](https://www.nhsa.gov.cn/) 与 [编码平台](https://code.nhsa.gov.cn/)。

结构化数据接口（连接器）按以下口径归类，不作为官方原文的替代：
- 天眼查（`tyc-mcp`）：工商登记、股东与实控、司法诉讼、被执行、行政处罚。归"监管/政府原始记录"的**派生数据**，其值来源于工商与司法公示，但经商业数据库加工。台账记查询日与权益档位；权益不足导致的空与真实无记录必须分开。
- 同花顺（`hithink-finance`）：A 股财务三表、指标、估值倍数。归"二手研究"——数据源自交易所披露，经加工与口径统一。记录 `thscode`、查询日与数据期；倍数随行情变动，不得写成时点不变的结论。

连接器都基于公开数据，**不能因其"权威"而视为对 BP 披露内容的独立交叉验证**。同一事实若 BP 与连接器一致，只说明 BP 与公开记录不矛盾，不说明 BP 的预测或商业判断成立。

全文摘录只保留核验所需的短句/表格定位；不能以存证为由复制不必要的敏感信息。
