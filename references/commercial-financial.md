# 市场准入、商业化、财务与融资

## 市场与支付

市场定义先固定产品/适应症、地区、时期、价格层级与客户。可用患者/适用手术数×可及率×采用率×使用量×价格自下而上测算，与外部总量比较；保留输入来源及假设，避免重复计入重叠应用。区分TAM、可服务市场及受注册、医院、产能、渠道约束的可获取市场。资料不足不强造精确规模或增长率。

按相关地区及生效日分别核对：产品编码、服务收费项目、支付范围/支付方式、采购/挂网/集采、医院准入、终端使用与现金回收。编码存在不自动等于能单独收费或获得支付。具体政策适用性查原始文件。

集采分别记录产品组别、地区、申报价/中选价、计价单位、约定量与实际执行。价格降幅、市场规模变动和产品渗透率不是同一指标。中标/挂网/勾选入院不直接等于实际采购、临床使用或回款。分析DRG/DIP、预算和临床工作流对采用的影响时用场景与事实，不从政策标题推定受益或受损。

渠道协议、合作意向、当地许可、订单、终端使用和确认收入分开。海外合作不能代替当地监管与实际商业化核验。

## 财务质量与业务模式

将历史实际、公司预测和研究者情景分别列示，注明未经审计/审计范围、单位与会计口径。防疫、贸易、一次性或非主营业务与核心器械收入分开；不同口径不直接计算增长趋势。

按适用性复核合同、交付/验收、发票、账面及回款，关注返利/退货、经销库存、关联交易、应收账龄、存货效期、毛利和售后成本。未取得账簿/流水时只能列核验计划，不能声称已核实财务质量。

- 未商业化：可用现金、受限资金、研发/注册投入、达到下一里程碑的资金需求与延期情景；
- 耗材：出厂与终端价格、终端消耗、渠道库存、复购、回款和降价；
- 设备＋耗材：装机与活跃装机、单机用量、耗材拉动、维保及服务成本；
- IVD：按实际模式观察试剂使用、仪器投放、检测量、价格与渠道，不照搬SaaS指标。

Runway只有在现金和可比消耗数据可得时计算，资本开支、里程碑付款、收入回款和融资到账时间另做情景，不把未到账融资当现金。

## 估值、交易与退出

先核对融资金额、投前/投后估值、资金用途、条款、股权稀释与历史融资。关键字段未披露时保留，并说明哪些计算无法进行。

有可比盈利才讨论PE；PS需解释产品、阶段、增长、渠道及利润结构可比性；DCF需有可解释的现金流与里程碑假设。未商业化项目可做透明的里程碑/情景分析，参数不足时不给伪精确“合理区间”。可比公司的日期、币种、市值与企业价值口径一致；历史可比倍数不写成当前行情。

将资金用途拆到里程碑、时间、预算和前置依赖，检查本轮能覆盖什么及后续融资需求。退出是路径与条件分析，不能承诺IPO时间或回报倍数；公司上市计划仅作为公司规划。

### 可自行计算的部分（不依赖外部建模工具）

以下四项只要有输入就能算，算出来比引用别人的结论可靠。输入缺失时列出缺哪个数，不要用行业平均值顶上。

**1. Runway 与缺口**

```
可用现金 = 货币资金 − 受限资金（保证金、质押、专户）
月净消耗 = 月经营现金流出 − 月经营现金流入
基准 runway（月） = 可用现金 ÷ 月净消耗
缺口 = 里程碑累计支出 − 可用现金 − 期间确认回款
```

分开列：资本开支、里程碑付款（如注册研究款、设备款）、回款到账时间。**未到账融资不计入可用现金**；已签约未到账的，单列“待收融资”并注明到账条件。延期情景按里程碑推后 N 个月、消耗不变重算，不假设期间新增融资。

**2. 投前投后与稀释**

```
投后估值 = 投前估值 + 本轮投资额
新投资人持股 = 本轮投资额 ÷ 投后估值
老股东稀释后持股 = 原持股 × (投前估值 ÷ 投后估值)
```

若 BP 只给投后估值，倒推投前 = 投后 − 投资额。历史轮次逐轮核：每轮金额、投前/投后、出让比例三者应自洽，不自洽就列为待核验，不挑一个当准。

**3. 倍数锚的算法与边界**

```
隐含估值 = 标的收入 × 可比 PS 区间
隐含估值 = 标的净利润 × 可比 PE 区间（仅在有盈利时）
```

- PS 只在标的有收入时可用；亏损标的的 PS 与盈利同行 PS 分母含义不同，**不可并列比较**；
- 无盈利不能用 PE，不要用“预测净利润”倒算出一个 PE 再当依据；
- 可比区间取中位数与分散度，报告写区间不写单点；样本 2–3 家时说明样本过少；
- 每个倍数记查询日与数据期，倍数随行情变动。

**4. 里程碑情景的三档**

对未商业化项目，用三档替代“合理估值”：乐观、基准、延期。每档写清触发条件、所需资金、对应里程碑与届时累计融资额。三档都算出缺口，让决策者看到哪一档会断粮。

以上四项算完，结论仍按“测算或推断”记账，输入保留，不因算得细就升格为“已核实事实”。
