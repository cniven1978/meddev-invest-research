# 范围精炼与任务路由

先读用户请求和已有资料，不强制发送固定问卷。提取以下会影响判断的信息：
- 对象是赛道、公司、具体产品/型号还是横向比较；
- 产品类型及预期用途，研发/临床/注册/商业化阶段；
- 本次是BP初筛、公开研究、尽调计划、已执行核验的纪要还是memo；
- 地域、研究截止日、资料清单、决策问题与输出偏好。

产品阶段与资料充分性不是一回事。已商业化公司也可能只有一份旧BP；临床前项目也可能已有详细数据包。

只对不能从资料判断且会改变任务的问题追问。可合理假设的非关键项先注明假设并开展独立工作。缺少财务/注册信息通常应成为报告缺口，不应自动阻断BP初筛。

生成简短研究指令：对象与边界、可用材料/工具、已核验范围、核心问题、交付形式、尚缺信息及处理方式。用户只问竞争时，不强制询问本轮融资；用户明确禁止联网时，按材料运行，并标明外部核验未做。

完整项目用六维研究；其他任务只读必要模块，BP先读后决定深挖。保留用户指定的判断阶段与称谓，不擅自升级成完整尽调或最终出资结论。
